RemoveBG Studio — استوديو تحرير الصور

هذه نسخة تطويرية للموقع الحالي. تحافظ على إعدادات Supabase الحالية ومسار Pixelcut المباشر الذي كان مستخدمًا في النسخة الأصلية. لا تضيف قاعدة بيانات جديدة أو وظائف Vercel أو مسارات API خادمية.

ما تغير في هذه النسخة
- صفحة بداية مستقلة بهوية H وتوقيع Haider، مع زر واضح لبدء التحرير واختصارات إلى الخدمات.
- صور معاينة محلية منفصلة للتحويلات الفنية (أنمي، ألوان زيتية، ألوان مائية، كوميك، رسم بالقلم، كرتون، أبيض وأسود وغيرها). هذه أمثلة لنتائج الأساليب الفنية وليست لقطات شاشة لواجهة الموقع.
- عند الضغط على خدمة من صفحة البداية، يختار المستخدم الصورة ثم تُفتح الخدمة المحددة مباشرة.
- بعد رفع الصورة، تظهر لوحة بداية داخل مساحة التحرير. يظل تخطيط المحرر ثابتًا قبل اختيار الخدمة وبعدها؛ إغلاق أداة يعيد لوحة البداية بدل إخفاء العمود الجانبي وتغيير توزيع الصفحة.
- محرك التحويلات الفنية المحلي أعيد بناؤه ليعطي اختلافًا مرئيًا أقوى: الأنمي والتلوين المسطح، الألوان الزيتية بملمس ضربات فرشاة، الألوان المائية، الكوميك والتنقيط، الرسم بالقلم، البكسلة، الأبيض والأسود والثنائي اللوني.
- تتم المعالجة الفنية على نسخة معاينة منخفضة الأبعاد نسبيًا لتقليل استهلاك ذاكرة الهاتف، ثم تُرسم النتيجة على مساحة الصورة الأصلية للتصدير.
- توقيع Haider يُضاف تلقائيًا على الصور الجديدة، ويظل ثابتًا في الركن السفلي الأيمن ولا يمكن سحبه أو تغيير موضعه.
- مكتبة الأصول تحتفظ بـ36 خلفية مختارة و14 تراكبًا بصريًا، مع بحث موسع في Openverse، ومكتبة ملصقات OpenMoji التي تُحمّل عند الطلب.
- تمت إضافة تصنيفات بحث سريعة إضافية للخلفيات والتراكبات لتسهيل الوصول إلى الموارد.
- معاينات الفلاتر تُبنى من الصورة التي رفعها المستخدم بدل رسومات عامة.
- اختيار خلفية من مكتبة الأصول أو رفع خلفية جديدة يشغّل إزالة الخلفية تلقائيًا مرة واحدة، ثم يركّب الخلفية خلف العنصر. بعد نجاح الفصل، لا تُعاد إزالة الخلفية عند اختيار خلفية أخرى.
- بقيت أدوات القص والتعديلات والرسم والأشكال والنصوص والملصقات والإطارات والطبقات والتصدير والحساب الشخصي والسجل ولوحة الإدارة.

الخدمات والأعداد
- 32 فلترًا.
- 10 تحويلات فنية (بالإضافة إلى الوضع الأصلي).
- 5 مؤثرات بصرية محلية قابلة للتحكم في الشدة.
- 18 إطارًا.
- 36 خلفية مختارة و14 تراكبًا خارجيًا، إضافة إلى نتائج Openverse عند البحث.
- مكتبة ملصقات OpenMoji الموسعة، مع المفضلة والأخيرة والبحث.

مهم بخصوص التحويلات الفنية
الأنمي والزيتية والمائية والكوميك في هذه النسخة معالجات Canvas محلية وليست توليدًا بالذكاء الاصطناعي. تعطي تغييرات لونية وخطية وملمسًا مرئيًا، لكن لا يمكنها إعادة رسم ملامح الشخص مثل نموذج توليدي متخصص. للحصول على تحويل توليدي أقرب إلى أعمال الأنمي الاحترافية، يلزم ربط مزود توليد صور خارجي بمفتاح API خاص بك؛ لم تتم إضافة خدمة مدفوعة أو مفتاح جديد هنا.

إزالة الخلفية وقاعدة البيانات
- يستخدم الموقع نقطة Pixelcut المباشرة نفسها الموجودة في config.js: PIXELCUT_DIRECT.
- تمت المحافظة على FormData ورؤوس الطلب وطريقة fetch في مسار الإزالة المباشر؛ لا توجد وظيفة خادمية جديدة.
- تحفظ الصور الأصلية والنتائج وسجل العمليات في Supabase الحالي باستخدام الجداول والمسارات والدوال الموجودة بالمشروع.
- لم تتم إضافة جداول أو تغيير أسماء bucket أو مفاتيح Supabase.
- إذا نجحت إزالة الخلفية وفشل حفظ السجل، تبقى النتيجة داخل المحرر وتظهر رسالة منفصلة.

مكتبة الأصول والتراخيص
- OpenMoji: https://openmoji.org/ — الرسومات بترخيص CC BY-SA 4.0؛ احتفظ ببيانات النسب والترخيص.
- Openverse: https://openverse.org/ و https://api.openverse.org/v1/ — تختلف التراخيص بحسب كل صورة؛ راجع صفحة المصدر والبيانات المعروضة قبل النشر.
- Unsplash: https://unsplash.com/license — راجع شروط الصور قبل الاستخدام التجاري أو إعادة النشر.
- تحميل الموارد الخارجية مباشر من المتصفح مع CORS. إذا كان مصدر محدد يمنع CORS، لن يستطيع المتصفح دمجه في Canvas أو تضمينه في التصدير؛ اختر نتيجة أخرى أو ارفع الملف من جهازك.

التشغيل والنشر
1. فك ضغط الأرشيف.
2. ارفع محتويات المجلد إلى جذر مستودع الموقع الحالي، مع الحفاظ على assets/service-previews.
3. انشر الموقع بالطريقة المعتادة لدى مزود الاستضافة الحالي؛ لا يلزم إعداد Vercel أو مسارات API إضافية.
4. لا تغيّر Supabase URL أو المفتاح العام أو bucket في config.js ما دامت إعدادات المشروع الحالي صحيحة.
5. تأكد من أن سياسات Storage الحالية تسمح للمستخدم المسجل برفع الملفات داخل مساره وقراءتها، وأن RPC create_removebg_operation موجودة كما في قاعدة البيانات الحالية.

الفحوصات المنفذة
- فحص صياغة app.js باستخدام Node.js.
- فحص HTML بحثًا عن المعرّفات المكررة والروابط المحلية غير الموجودة.
- تحليل CSS والتحقق من عدم وجود أخطاء تركيب.
- فحص سلامة أرشيف ZIP بعد إنشائه.
- لم يُنفذ اختبار متصفح بصري كامل أو طلب فعلي بمفتاح Pixelcut الحقيقي وحساب Supabase الخاص بك من بيئة البناء.
