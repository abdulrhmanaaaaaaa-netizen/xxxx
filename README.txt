RemoveBG — Sandstorm Studio

The existing RemoveBG app has been given a cinematic sepia / bronze / gold visual redesign.

Files:
- index.html: updated header, theme controls, and hero artwork
- styles.css: responsive design and three palettes
- app.js: theme switching and longer staged loading screen

Deployment: upload the contents of this folder to the same static hosting location as before.
The project's existing Supabase and image-processing configuration has been preserved.
