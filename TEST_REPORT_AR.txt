تقرير نسخة RemoveBG بدون اعتماديات npm

- أزيل package.json عمدًا؛ لا توجد أي اعتماديات npm مطلوبة.
- أزيل اعتماد Axios من دالة Nano Banana واستبدل بطلب fetch الأصلي.
- أزيل node-upload-images واستبدل رفع Pixhost بطلب multipart/form-data عبر FormData وBlob المدمجين.
- أزيل استخدام Buffer واستبدل Uint8Array وTextDecoder.
- لا تحتاج دالة Pages إلى nodejs_compat لأنها لا تستورد Node.js APIs أو حزم npm.
- build.mjs يستخدم وحدات Node الأساسية فقط لتجهيز مجلد dist.
- يبقى مجلد functions في جذر المستودع منفصلًا عن dist.
- ملف config.js لم يُغيّر.

تم فحص صياغة ملفات JavaScript وتجهيز dist محليًا، والتأكد من غياب استيرادات Axios وnode-upload-images وBuffer.
لم يتم تنفيذ رفع Pixhost أو استدعاء Nano Banana فعليًا من بيئة البناء، لذلك يجب تجربة تحويل صورة غير حساسة بعد النشر.

ملاحظة الدقة: Pixhost API v2 يعيد show_url وth_url؛ الدالة تحاول استخراج رابط الصورة الأصلي من صفحة العرض، ثم تستخدم th_url كخيار احتياطي. رابط thumbnail قد لا يتجاوز 500 بكسل.
