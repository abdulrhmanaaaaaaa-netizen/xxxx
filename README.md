# RemoveBG — استوديو الصور

واجهة عربية لتحرير الصور وإزالة الخلفيات، مبنية بملفات HTML وCSS وJavaScript عادية، مع الحفاظ على وظائف التطبيق الحالية.

## هيكل المشروع

- `index.html`: نقطة الدخول للواجهة.
- `assets/css/styles.css`: قواعد التصميم الأساسية.
- `assets/css/human-touch.css`: الهوية البصرية الجديدة، تحسينات الوضوح وتجربة الهاتف.
- `assets/js/app.js`: منطق التطبيق وأدوات المحرر وتسجيل الدخول والسجل ولوحة الإدارة.
- `.en/config.js`: إعدادات الاتصال وحدود الاستخدام.
- `.nojekyll`: يساعد GitHub Pages على نشر الملفات التي تبدأ أسماؤها بنقطة.
- `SECURITY.md`: ملاحظات مهمة عن المفاتيح والإعدادات العامة.

## التشغيل والنشر

1. ارفع محتويات الحزمة إلى جذر المستودع، بحيث يكون `index.html` في الجذر مباشرة.
2. فعّل GitHub Pages من إعدادات المستودع، واختر الفرع والمجلد الذي يحتوي `index.html`.
3. تأكد من أن إعدادات Supabase وسياسات قاعدة البيانات والتخزين تطابق مشروعك.
4. افتح رابط الموقع واختبر تسجيل الدخول ورفع صورة وحفظ نتيجة قبل مشاركة الموقع.

المشروع لا يحتاج إلى خطوة بناء أو مدير حزم؛ يعتمد على ملفات المتصفح الحالية.

## تنبيه

مجلد `.en` لتنظيم الإعدادات وليس وسيلة لإخفائها. ملفات JavaScript التي يحملها المتصفح يمكن لأي زائر فحصها. لا تضع مفاتيح سرية أو كلمات مرور إدارية داخل هذا المشروع.
