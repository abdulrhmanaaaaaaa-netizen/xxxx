RemoveBG — Sandstorm Studio

A polished visual redesign of the existing RemoveBG image editor, inspired by aged bronze, desert-gold, and cinematic fantasy artwork.

Included files
- index.html: Arabic right-to-left interface, authentication screen, editor views, and loading screen.
- styles.css: responsive interface styling and three selectable themes.
- app.js: existing editor, authentication, account history, and administration behavior with updated Arabic interface wording.
- config.js: existing service settings and a staged 6-second visual loading sequence.
- brand.svg: custom vector emblem designed for the Sandstorm Studio visual identity.
- assets/desert-warrior.webp: optimized original cinematic artwork used in the loading screen, sign-in panel, and editor hero.
